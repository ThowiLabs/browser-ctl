## Tarea 07 - eval no invoca la función (completado)
- Causa: `Engine.eval` pasaba la expresión tal cual a Runtime.evaluate, así que una función flecha se serializaba como `{}`.
- Cambio (`internal/engine/reads.go`): `doEval` ahora envuelve la expresión en `wrapEvalExpr`: si evalúa a función, la invoca con el elemento objetivo como argumento (o `undefined` sin target); un valor plano pasa tal cual. El target opcional (2º argumento) se resuelve con la nueva `ResolveTargetSess` (`internal/engine/targets.go`), que usa la tabla de refs del snapshot para las refs. Además `formatEvalValue` imprime strings sin comillas JSON (null se distingue por tipo: unmarshalar null a string no da error).
- Hallazgo durante la prueba: `axNodeExpr` (`internal/engine/snapshot.go`) buscaba solo `[role="link"]`, que no casa con `<a>` (los roles implícitos no son atributo). Ahora la consulta cubre atributo de rol y etiqueta implícita (`[role="link"],a`) usando el `roleTag` que ya existía. Esto arregla también la resolución de refs para fill/check/select/get con elementos de rol implícito.
- Pruebas unitarias nuevas: `internal/engine/eval_test.go` (TestWrapEvalExpr, TestFormatEvalValue).
- Verificación en vivo en https://example.com (con daemon reiniciado tras el rebuild, porque el daemon viejo seguía sirviendo el binario anterior): `eval "() => document.title"` devuelve `Example Domain`; `eval "() => 1 + 1"` devuelve `2`; `eval "document.title"` devuelve `Example Domain`; `eval "function(el){ return el.textContent; }" e1` devuelve `Learn more`; `eval "(el) => el.getAttribute('href')" e1` devuelve `https://iana.org/help/example-domains`.
- Lección: tras cada rebuild hay que reiniciar el daemon (`browser-ctl.exe shutdown`) o la prueba en vivo corre contra el binario viejo.

## Tarea 03 - Resolución de locators por ARIA (completado)
- Parser (`internal/engine/commands.go`): `mergeTargetArgs` junta un target locator de varias palabras en un solo argumento para click/hover/check/uncheck/screenshot/snapshot, target+texto para fill/select y target final para get. Solo se junta cuando el primer token es un método locator (así `fill e12 hello world` sigue fallando por MaxArgs). drag/upload y targets en flags (--gone, --in) quedan fuera: deuda-tecnica en el comentario.
- Forma con espacios (`internal/engine/targets.go`): `parseSpaceLocator` acepta `getByRole button "Nombre"`, `getByText texto`, `getByLabel`, `getByTestId`, `locator`; el nombre es todo lo que sigue al rol. Las comillas se quitan (`unquoteLiteral`) porque ParseTarget también se llama sin tokenizar. Un método locator solo sin argumentos es error, no CSS. El encadenado (.first(), .nth()) solo existe en la forma con paréntesis.
- Resolución por AX: el snapshot guarda `LastAX` (ref, rol, nombre accesible, en orden de documento) en la sesión. `resolveLocatorAX` casa getByRole (con alias textbox/searchbox, nombre por subcadena insensible a mayúsculas o exacto con {exact: true}), getByLabel (nombre accesible del control) y getByText, con .first()/.last()/.nth()/.filter({hasText}). Sin coincidencia se usa la traducción JS de siempre (cubre elementos fuera del snapshot). `ResolveTargetSess` y `resolveBoxSess` usan AX primero (el click llega al nodo DOM preciso por backend id); `countForTarget` da el conteo exacto por AX. fill/check/select/download/upload también pasan por ResolveTargetSess/nodeIDForTarget.
- Hit-test (`internal/engine/actions.go`): `checkActionable` ahora compara el elemento en el punto del click con el objetivo (elementFromPoint): si otro elemento lo cubre, error claro en vez de éxito silencioso. Para refs usa la vía precisa (DOM.resolveNode + Runtime.callFunctionOn); las refs de iframe saltan el hit-test (deuda-tecnica: requeriría evaluar en el contexto del frame).
- Pruebas unitarias nuevas: `internal/engine/targets_test.go` (parseSpaceLocator, mergeTargetArgs, resolveLocatorAX con exact/first/last/nth, nameMatches, roleMatches).
- Verificación en vivo: en https://example.com, `snapshot` + `get count getByRole link "Learn more"` devuelve 1 y `click getByRole link "Learn more"` navega a "Example Domains". Hit-test: con un div overlay cubriendo la página, el click falla con "element is covered by another element at its centre"; al quitar el overlay, el click funciona. En Studio, `click getByRole button "Crear"` abre el menú (find muestra "Subir videos") y Escape lo cierra.
